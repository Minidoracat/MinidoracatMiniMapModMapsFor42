[h1]🗺️ Minidoracat MiniMap - MOD Maps for B42[/h1]
[h3]By Minidoracat[/h3]

[hr][/hr]

Shows real map images, area outlines and map names for map mods on the minimap and world map. Only the map mods you have enabled are drawn.

[h2]📦 What you need[/h2]
[list]
[*] Required: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3763913359]Minidoracat MiniMap for B42[/url] (main mod) and its requirement [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3789836701]Minidoracat UI Library for B42[/url]
[*] The map mods you want to play: this pack only provides the images, so the maps themselves must be subscribed separately
[/list]
Keep every Minidoracat MiniMap series mod up to date and restart the game after updating.

[h2]🚀 Quick start[/h2]
[olist]
[*] Subscribe to the main mod and this pack
[*] Pick map mods from the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3766382352]supported maps collection[/url], then subscribe and enable them
[*] In game, press [b]/[/b] for the minimap or [b]M[/b] for the world map — the map area shows its image, outline and name
[/olist]

[h2]✨ Features[/h2]
[list]
[*] Supports [b]78 map mods (101 maps)[/b], shown automatically when enabled
[*] Map outlines and map names in four languages; outlines can be toggled and recoloured
[*] Street names on 16 maps are translated into Traditional Chinese, Simplified Chinese and Japanese; both original and translated names are searchable
[*] Road data fixed or added by this pack on some maps, for more complete street names, search and navigation (for example, 37 added roads in Constown)
[*] Display only — terrain, buildings and saves are never changed
[/list]
📖 [b]Full supported list (including which maps have road data), conflict notes and map requests:[/b] [url=https://steamcommunity.com/workshop/filedetails/discussion/3763914102/586187095760050601/]Map Requests & Supported Maps[/url]
