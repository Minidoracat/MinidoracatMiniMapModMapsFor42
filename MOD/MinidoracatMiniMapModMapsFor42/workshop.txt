title=Minidoracat MiniMap - MOD Maps for B42
description=[h1]🗺️ Minidoracat MiniMap - MOD Maps for B42[/h1]
description=[h3]By Minidoracat[/h3]
description=
description=[hr][/hr]
description=
description=Shows real map images, area outlines and map names for map mods on the minimap and world map. Only the map mods you have enabled are drawn.
description=
description=[h2]📦 What you need[/h2]
description=[list]
description=[*] Required: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3763913359]Minidoracat MiniMap for B42[/url] (main mod) and its requirement [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3789836701]Minidoracat UI Library for B42[/url]
description=[*] The map mods you want to play: this pack only provides the images, so the maps themselves must be subscribed separately
description=[/list]
description=Keep every Minidoracat MiniMap series mod up to date and restart the game after updating.
description=
description=[h2]🚀 Quick start[/h2]
description=[olist]
description=[*] Subscribe to the main mod and this pack
description=[*] Pick map mods from the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3766382352]supported maps collection[/url], then subscribe and enable them
description=[*] In game, press [b]/[/b] for the minimap or [b]M[/b] for the world map — the map area shows its image, outline and name
description=[/olist]
description=
description=[h2]✨ Features[/h2]
description=[list]
description=[*] Supports [b]78 map mods (101 maps)[/b], shown automatically when enabled
description=[*] Map outlines and map names in four languages; outlines can be toggled and recoloured
description=[*] Street names on 16 maps are translated into Traditional Chinese, Simplified Chinese and Japanese; both original and translated names are searchable
description=[*] Road data fixed or added by this pack on some maps, for more complete street names, search and navigation (for example, 37 added roads in Constown)
description=[*] Display only — terrain, buildings and saves are never changed
description=[/list]
description=📖 [b]Full supported list (including which maps have road data), conflict notes and map requests:[/b] [url=https://steamcommunity.com/workshop/filedetails/discussion/3763914102/586187095760050601/]Map Requests & Supported Maps[/url]
description=
description=[h2]🔗 Minidoracat MiniMap series[/h2]
description=[list]
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3763913359]MiniMap for B42[/url] (main mod, required) — image-based world map and minimap, search, navigation
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3763914102]MOD Maps[/url] — map images and street-name translations for map mods
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3792675881]AutoDrive[/url] — GPS navigation and autonomous driving
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3768276209]Zones[/url] — custom server zones
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3765182411]MOD Compatibility[/url] — icons for third-party animals such as dogs and horses
description=[/list]
