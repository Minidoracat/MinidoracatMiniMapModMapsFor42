[h1]📍 Map Requests & Supported Maps[/h1]
The supported-map list, road data, conflict notes and FAQ have moved to a Steam guide. They are only updated there:
https://steamcommunity.com/sharedfiles/filedetails/?id=3817840392

Want a map mod supported? Comment below, or use the [url=https://github.com/Minidoracat/MinidoracatMiniMapModMapsFor42/issues/new/choose]GitHub issue form[/url] (it goes straight into the dev backlog — fastest).

[h2]📝 How to request[/h2]
[list]
[*] The map mod's Workshop link (required)
[*] A short note (optional), e.g. "our server uses it"
[/list]
More requests for the same map mean higher priority (+1 on someone else's request counts). Very large maps may ship as a separate pack.
